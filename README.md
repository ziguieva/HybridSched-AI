# HybridSched-AI

Learning-Based Scheduling for Hybrid Cloud & HPC Clusters.

## Research objective

Develop and evaluate scheduling algorithms combining
runtime prediction, uncertainty quantification, and
constrained optimization for heterogeneous compute clusters.

## Environment

- Python 3.12
- macOS Apple Silicon
- Visual Studio Code

## Run

    python -m hybridsched

## Tests

    python -m pytest -q
